# Come pubblicare dati in CSV

Quindici regole per pubblicare dati in CSV che altri possano riusare senza doverli ripulire.

Se pubblichi dati in tabella per un Comune, un ente o un'associazione, questa guida ti dice come preparare il file. Non serve saper programmare: bastano un foglio di calcolo e un editor di testo, più LibreOffice Calc se Excel esporta con `;` e con la virgola nei decimali.

Un CSV è un file di testo: ogni riga è una riga della tabella, con i valori separati da un carattere, di solito la virgola.

```
codice_istat_comune,comune,abitanti
082053,Palermo,635439
001168,None,7830
019028,Cella Dati,486
```

None, in provincia di Torino, e Cella Dati, in provincia di Cremona, sono comuni veri; gli abitanti sono la popolazione legale del censimento 2021 (Istat).

Il CSV si apre ovunque, ed è il formato più presente su [dati.gov.it](https://www.dati.gov.it/). Però non dice se una colonna contiene numeri o date, né se un valore è obbligatorio: queste regole servono a colmare quel vuoto.
